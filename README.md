# Learn Playwright Batch 2x

Beginner-friendly JavaScript learning repository organized by chapters. This repo currently focuses on JavaScript fundamentals and VS Code productivity basics.

## Prerequisites

- Node.js installed
- VS Code (recommended)

## How to Run Files

1. Open terminal in this repository root.
2. Run any file using Node:

```bash
node chapter_01_Basics/01_basics.js
```

You can replace the path with any lesson file.

## Suggested Learning Order

1. Start with Chapter 01 files in order.
2. Move to Chapter 02 and read the chapter README.
3. Continue with Chapter 03 for naming, comments, and editor productivity.
4. Progress to Chapter 04 to master JavaScript fundamentals:
   - Begin with the Variables folder to understand var, let, and const
   - Then study the Hoisting files in order (18-22) to understand how JavaScript handles variable declarations
   - Focus especially on files 19-22 for a deep understanding of Temporal Dead Zone (TDZ)
5. Chapter 05: Learn arithmetic operators (file 23).
6. Chapter 06: Explore literals - null, undefined, strings, template literals, and quote types (files 24-29).
   - Pay special attention to 28 and 29 to master template literals and quote differences.
7. Chapter 07: Deep dive into all operators - arithmetic, comparison, logical, ternary, nullish, increment/decrement, typeof, and primitives.
8. Chapter 08: Practice common interview programming questions on operators.
9. Chapter 09: Understand primitive vs non-primitive data types and how reference types work.
10. Chapter 10: Master control flow statements:
    - Start with file 51 for comprehensive statement overview
    - Study file 52 to master IF, IF-ELSE, and IF-ELSE IF statements
    - Practice with file 53 for simple ELSE IF examples
    - Solve interview questions in file 54 to reinforce learning
